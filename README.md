# Facebook Marketplace Scraper API  

This project provides an **API service** that allows you to scrape product listings from **Facebook Marketplace** for different cities in Tanzania.  

## 🎯 Use Case  

The API is designed to help:  
- **Businesses** – Collect real-time marketplace data to analyze pricing, trends, and product availability across different cities.  
- **Buyers** – Search products by keyword in their local marketplace without manually browsing through Facebook.  
- **Market Analysts / Researchers** – Gather structured information about second-hand goods and services to understand demand and supply patterns in specific regions.  
- **Developers** – Integrate Facebook Marketplace data into custom dashboards, comparison tools, or price-tracking applications.  

With this API, you can query a city and a product keyword, and get structured data such as:  
- Product **image**  
- Product **title**  
- **Price**  
- **Location**  
- Direct **post link**  
- Search **category**  

This eliminates the need for manual searching and makes Marketplace data accessible in an automated and structured way.
